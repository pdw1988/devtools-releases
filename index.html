常见问题

和 Navicat / DataGrip 有什么不同？

Navicat、DataGrip 是数据库客户端，解决的是「连上库之后」的操作。CHUJU SQL 补的是更前面的那一步：不连库也能基于表结构生成可执行的 SQL。日志参数回填、查询结果转 UPDATE 是它的差异化能力；连库功能只是为了少切换一次窗口。

表结构、SQL 会上传吗？

不会。所有解析与生成均在本机完成，产品没有任何数据上报通道。生产库密码不落盘，每次连接时输入；测试库密码可存入系统凭据管理器。许可码仅在本机校验。

两个 Windows 安装包怎么选？

普通包体积更小，支持应用内自动更新。如果本机已配置 Oracle 客户端（PATH 中已有 oci.dll，例如 PL/SQL Developer、Instant Client 或完整客户端），或只需连接 Oracle 12.1+ / MySQL / PostgreSQL，选择普通包即可。需要连接 Oracle 11g 且本机没有客户端时，选择「含 Oracle 11g 客户端」安装包：内置 Instant Client 19c，无需另行下载。该包约 105MB，超出 Git 仓库 100MB 限制，因此作为 GitHub Release 附件发布，不参与自动更新。

Windows 提示「已阻止」怎么办？

安装包尚未购买代码签名证书，首次运行可能触发 SmartScreen 提示。点击「更多信息 → 仍要运行」即可。请仅从本页面或 GitHub 产物仓库下载安装包，不要使用网盘转载的版本。
