常见问题

和 Xshell、Postman、Navicat 有什么不同？

它们各管一段；码上 CodeNow 管的是「改完代码→确认没问题→出事查日志」这一整段。日志不用登服务器 less，拉下来就能按列筛；接口不用一个个手录，扫一遍工程就全有，用例和测试数据自动生成，跑完自动清理。

试用怎么开？到期会怎样？

装好后点左下角「免费」标签或任一专业功能，在弹出的卡片里点「免费试用 7 天」，不用加微信、不用注册。到期自动回免费版，导过的表、收藏、连接都还在。每台电脑可以试用一次。

表结构、日志、密码会上传吗？

不会。所有解析与生成均在本机完成，产品没有任何数据上报通道；码上测只向你自己填的服务地址发请求。生产库密码不落盘，每次连接时输入；测试库和服务器密码可存入系统凭据管理器。许可码仅在本机校验。

安装版和免安装版怎么选？

一般选安装版，支持应用内「检查更新」自动升级。免安装版是单个 exe，双击就能用，适合没有安装权限的电脑；升级要自己下载新版替换。连 Oracle 11g 需要本机有 Oracle 客户端（PL/SQL Developer 或 Instant Client 自带即可）；Oracle 12c+ / MySQL / PostgreSQL 不需要。

GitHub 下载太慢怎么办？

到 Gitee 镜像 下载，内容一样。应用内「检查更新」连不上 GitHub 时也会自动走 Gitee。

Windows 提示「已阻止」怎么办？

安装包尚未购买代码签名证书，首次运行可能触发 SmartScreen 提示。点击「更多信息 → 仍要运行」即可。请仅从本页面或 GitHub 产物仓库下载安装包，不要使用网盘转载的版本。
