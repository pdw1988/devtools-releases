## 它做什么

- **码上查**：导入 DDL / 连库拿表结构，生成批量 INSERT 测试数据，连库查询、优化记录
- **码上写**：YAML / Properties / JSON 互转校验
- **码上测**：扫 Spring Boot 工程出全部接口，生成并回归接口测试（支持 uni-app / Vue 页面测试）
- **码上运维**：日志查看（本机大日志秒开、按 pattern 拆列过滤、连服务器拉日志）+ SSH 终端与服务器文件互传
- **小工具**：JSON 树形查看、Cron 表达式解读

免费版覆盖日常；专业版解锁连库导入、SSH / 日志、接口回归等（应用内激活）。
